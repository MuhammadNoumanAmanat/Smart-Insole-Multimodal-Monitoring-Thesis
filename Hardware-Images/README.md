# Hardware prototypes and experimental visualizations

This directory contains the selected project images and reported experimental output figures.

- **[Hardware prototype photographs](Hardware_Prototype/)** — photos of the wearable insole and electronics housing.
- **[Results and visualizations](Results/)** — FSR pressure monitoring, sensitivity plots, sensor input radar, pulse-oximetry and temperature/humidity measurements, gait-cycle results, and experimental classification figures.
- **[Initial hardware demonstration](../Hardware_Initial_Demo.mp4)** — short video demonstrating an early hardware prototype.

These are documentation/evaluation assets from the FYP, not independently verified clinical evidence. Code and datasets are not publicly released.
